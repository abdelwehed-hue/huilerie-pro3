# Oro Verde — Public Website

A standalone multilingual public-facing website for the Oro Verde olive mill, built with React and Vite.

## Development
```bash
cd website
npm install
npm run dev
```

## Production build
```bash
npm run build
```

The static output is written to `website/dist` when building from the repository root with the Render command documented below.

## Render Static Site
- Branch: `website/oro-verde-v1`
- Build command: `cd website && npm install && npm run build`
- Publish directory: `website/dist`

## Launch checklist
- Replace editorial/demo product photography with approved Oro Verde assets.
- Confirm company address, phone, WhatsApp and official email.
- Confirm product names, packaging sizes, prices, stock and delivery regions.
- Connect order submission to a secure backend and configure payment provider(s).
- Add privacy, terms, shipping, returns and cookie notices as applicable.
- Configure production domain only after the site and existing app domain plan are verified.

The cart and enquiry form in this first visual version are front-end previews only. They do not transmit orders or collect payment.
